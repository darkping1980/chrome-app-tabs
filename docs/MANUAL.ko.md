# Chrome App Tabs 설치·업데이트·사용·제거 설명서 (v0.3.2)

최신 버전, 스크린샷, FAQ: https://github.com/darkping1980/chrome-app-tabs

App Tabs는 지금 쓰고 있는 Chrome의 탭 표시줄에 **이미 실행 중인 Windows 프로그램 창**을 탭처럼 추가합니다.
그 탭을 고르면 프로그램 창이 Chrome 화면 영역에 겹쳐 표시되고, 다른 탭을 고르면 프로그램 창은 Chrome 뒤로 물러납니다.

## App Tabs가 하는 일 / 하지 않는 일

| 합니다 | 하지 않습니다 |
|---|---|
| 프로그램 창의 **위치, 크기, 표시 여부, 앞뒤 순서, 포커스**만 바꿉니다 | 프로그램 설치 파일이나 설정을 수정하지 않습니다 |
| 연결을 해제하거나 오류가 나면 창을 **원래 위치와 크기**로 되돌립니다 | DLL 주입이나 메모리 접근, 창 강제 삽입(SetParent)을 하지 않습니다 |
| 모든 일반 창을 같은 방식으로 다룹니다 | 프로그램을 종료하지 않습니다 (탭을 닫아도 프로그램은 계속 실행) |
| | Chrome 프로필, 로그인, 쿠키, 북마크, 다른 확장을 바꾸지 않습니다 |

## 1. 준비물
- Windows 11 64비트에서 검증했습니다(Windows 10은 미검증). Google Chrome 전용입니다(Chrome 158에서 검증, Edge 등 다른 브라우저 미지원)
- 관리자 권한 불필요, 추가 설치 프로그램 불필요(.NET Framework 4.x는 Windows 기본 포함)

## 2. 내려받기
1. GitHub 저장소의 **Releases**에서 최신 `ChromeAppTabs-vX.Y.Z.zip`을 내려받습니다.
2. (선택) 같은 페이지의 `.sha256` 파일 값과 비교해 파일이 손상되지 않았는지 확인할 수 있습니다.
   ```powershell
   Get-FileHash .\ChromeAppTabs-v0.3.2.zip -Algorithm SHA256
   ```
3. zip 파일을 마우스 오른쪽 버튼으로 눌러 **압축 풀기**를 합니다. 위치는 아무 곳이나 괜찮습니다(예: 다운로드 폴더).

## 3. 신규 설치
1. 압축을 푼 폴더에서 **`Install-or-Update.cmd`**를 더블클릭합니다.
   - 설치 스크립트는 다음 세 가지를 합니다.
     - 파일 손상 여부를 확인합니다.
     - `%LOCALAPPDATA%\ChromeAppTabs\app`에 파일을 복사합니다.
     - 현재 사용자 레지스트리 키 1개를 등록합니다.
   - 무엇이 바뀌는지 미리 보려면 PowerShell에서 `.\setup.ps1 -DryRun`을 실행합니다.
2. Chrome에서 한 번만 확장을 로드합니다.
   1. 주소창에 `chrome://extensions`를 입력하고, 오른쪽 위 **개발자 모드**를 켭니다.
   2. **압축해제된 확장 프로그램을 로드합니다**를 누르고 다음 폴더를 선택합니다.
      `%LOCALAPPDATA%\ChromeAppTabs\app\extension` (탐색기 주소창에 그대로 입력하면 이동합니다)
   3. App Tabs의 ID가 `bahmlmpijalpgcnbnkgplggendgjhdlk`인지 확인합니다.
3. 툴바의 **App Tabs** 아이콘을 누르면 오른쪽 위에 **호스트 v0.3.2 연결됨**이 표시됩니다.

## 4. 업데이트 (예: v0.2.0 → v0.3.0)
1. 새 버전 zip을 내려받아 압축을 풀고 **`Install-or-Update.cmd`**를 실행합니다.
   - App Tabs가 실행 중이면 계속할지 묻습니다(Y).
   - **App Tabs 연결 프로그램만** 잠시 종료합니다. Chrome, VS Code 같은 다른 프로그램은 종료하지 않습니다.
   - 탭으로 연결돼 있던 프로그램 창은 원래 위치로 돌아갑니다. 저장하지 않은 작업 내용은 그대로입니다.
   - 설치 경로, 확장 ID, 연결 정보, 설정은 그대로 유지됩니다. 확장 프로그램을 **삭제하거나 다시 설치할 필요가 없습니다**.
2. Chrome에서 `chrome://extensions`를 열고 **App Tabs 카드의 새로고침(↻) 버튼을 한 번** 누릅니다.
3. 새로고침하면 열려 있던 프로그램 탭이 닫힐 수 있습니다. App Tabs 팝업의 **탭 다시 열기**로 다시 여세요(연결 정보는 그대로 남아 있습니다).

참고: 새 버전 파일이 설치됐는데 아직 새로고침하지 않았다면, App Tabs 팝업 위쪽에 "새 버전이 설치되었습니다" 안내가 나타납니다(v0.3.0부터).

### 업데이트가 실패하면
새 버전을 별도 폴더에 준비해 확인한 뒤 기존 폴더와 바꿔치기합니다. 바꾸는 도중 문제가 생기면 **자동으로 이전 버전으로 되돌립니다**. 화면에 "이전 상태로 복구했습니다"가 나오면 이전 버전을 계속 쓸 수 있습니다.
직전 버전 3개는 `%LOCALAPPDATA%\ChromeAppTabs\backup`에 보관됩니다.
- 손상된 zip은 설치를 시작하기 전에 거부됩니다.
- 더 오래된 버전으로 되돌리려면 그 버전 패키지에서 `setup.ps1 -AllowDowngrade`를 실행합니다.

## 5. 사용 방법

### 프로그램을 탭으로 추가하기
- **방법 1 — 끌어다 놓기 (v0.3.0)**
  1. 프로그램 창의 **제목 표시줄**을 마우스로 잡습니다.
  2. Chrome 창의 **탭 표시줄**(탭이 있는 맨 윗줄)로 끌고 갑니다. 파란색 "여기에 놓으면 Chrome 탭으로 추가" 표시가 나타납니다.
  3. 그 위에서 마우스를 놓으면, 놓은 그 Chrome 창에 프로그램 탭이 생깁니다.
  - 탭 표시줄 밖에서 놓으면 평소처럼 창만 이동합니다.
  - 끄는 도중 **Esc**를 누르면 취소되고, 창이 제자리로 돌아갑니다.
  - 이미 탭으로 연결된 프로그램은 다시 추가되지 않습니다.
- **방법 2 — 팝업**: 툴바의 App Tabs 아이콘 → **프로그램 추가** 목록에서 창을 클릭합니다. 검색칸에 창 제목이나 프로그램 이름 일부를 입력하면 목록이 좁혀집니다.

탭 이름은 실행 파일 설명(예: "Visual Studio Code")으로 정해지고, 프로그램 아이콘이 탭 아이콘으로 표시됩니다.

### 탭 전환과 단축키
- 웹 탭을 누르면 웹페이지가, 프로그램 탭을 누르면 프로그램이 보입니다. 키보드·마우스 입력은 프로그램에 그대로 전달됩니다.
- 프로그램에 포커스가 있어도 동작하는 전용 단축키:

| 단축키 | 동작 |
|---|---|
| `Ctrl+Shift+7` | 프로그램 탭 ↔ 직전 웹 탭 |
| `Ctrl+Shift+8` / `Ctrl+Shift+9` | 이전 / 다음 탭 |

  단축키를 바꾸려면 팝업의 **단축키 변경…**을 누르세요(범위를 "전역"으로 두어야 프로그램에 포커스가 있을 때도 동작합니다).

### 주소창 사용
프로그램 탭에서 주소창을 클릭하면 프로그램이 잠시 뒤로 물러나 자동완성 목록이 보입니다.
- **Esc**를 누르거나 탭 영역을 클릭하면 프로그램이 다시 나타납니다.
- 주소를 입력하고 Enter를 누르면 그 탭은 웹 탭이 되고, 프로그램은 원래 위치로 돌아갑니다.

### 관리 (팝업 "연결된 프로그램")
- **이름 변경**: 이름 칸을 고치고 Enter.
- **이동**: 해당 탭으로 이동.
- **탭 다시 열기**: 탭이 닫혔지만 연결 정보가 남아 있을 때 탭을 다시 엽니다.
- **연결 해제**: 탭을 닫고 프로그램을 원래 위치로 되돌립니다(종료하지 않음).

### 설정 (팝업 아래쪽)
- 다른 탭 선택 시: "Chrome 뒤로 보내기"(권장) 또는 "최소화"
- 주소창을 쓰는 동안 프로그램을 잠시 숨기기: 켬/끔
- 프로그램 제목 표시줄을 Chrome 탭 표시줄로 끌어다 놓아 추가: 켬/끔 — 끄면 창 이동이 완전히 평소대로 동작합니다.

## 6. 문제가 생겼을 때

| 증상 | 조치 |
|---|---|
| 팝업에 "호스트 연결 실패" | 압축을 푼 폴더에서 `check.ps1`을 실행해 결과 확인 → 필요하면 `Install-or-Update.cmd` 다시 실행 |
| 팝업에 "새 버전이 설치되었습니다" | `chrome://extensions`에서 App Tabs 새로고침(↻) |
| 프로그램 창이 엉뚱한 위치에 남음 | 팝업에서 **연결 해제**, 또는 Chrome에서 App Tabs를 껐다 켜기(창이 원래 위치로 복원됨) |
| Chrome이 갑자기 종료됨 | 별도 감시 프로세스가 프로그램 창을 원래 위치로 되돌립니다 |
| 로그 | `%LOCALAPPDATA%\ChromeAppTabs\host.log` |

## 7. 제거
1. `chrome://extensions`에서 App Tabs를 **삭제**합니다.
2. 압축을 푼 폴더에서 **`Uninstall.cmd`**를 실행합니다(또는 `uninstall.ps1 -Purge`로 로그까지 삭제).
   - 연결돼 있던 창을 원래 위치로 되돌린 뒤 레지스트리 키와 설치 폴더를 지웁니다.
   - Chrome과 다른 프로그램은 종료하지 않습니다.

## 8. 알려진 한계 (v0.3.2)
- **최대화된 Chrome 창**은 탭 표시줄이 화면 맨 위에 붙어 있습니다. 그곳에 끌어다 놓을 때 Windows Snap(맨 위로 끌면 최대화)이 먼저 동작할 수 있습니다. 이 경우 탭은 추가되지 않고 창만 최대화됩니다. 데이터에는 영향이 없으며, 팝업으로 추가하거나 Chrome을 최대화하지 않은 상태에서 끌어다 놓으세요.
- 프로그램 자체 제목 표시줄이 보이고, 그 안의 닫기(X)를 누르면 프로그램이 실제로 종료됩니다.
- 업데이트 후 확장 새로고침(↻)은 직접 눌러야 하며, 새로고침하면 프로그램 탭이 닫힙니다("탭 다시 열기"로 복구).
- UWP 앱(계산기 등)은 탭 이름이 "Application Frame Host"로 표시됩니다(이름 변경으로 수정 가능).
- 화면 배율(DPI)이 서로 다른 모니터 사이 이동, 관리자 권한 프로그램은 아직 검증하지 않았습니다.
